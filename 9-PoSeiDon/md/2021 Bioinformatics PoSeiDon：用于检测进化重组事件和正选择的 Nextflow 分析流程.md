> PoSeiDon: a Nextflow pipeline for the detection of  evolutionary recombination events and positive  selection

# 摘要
**PoSeiDon** 是一套易于使用的分析流程，可用于在**蛋白编码序列**中**识别重组事件**及受**选择作用**的位点。

用户输入同源序列后，**PoSeiDon 会构建序列比对、估计最佳替换模型，并执行重组分析，随后生成所有相应的系统发育树**。最终，该流程基于**多种模型**分别对完整比对和潜在重组片段中的显著[[正选择(Positive selection)]] 位点进行检测。

PoSeiDon 的结果将以用户友好的 HTML 页面呈现，包含所有中间结果以及重组事件和正选择位点的可视化展示。

# 介绍
## 研究背景
**选择压力持续影响基因的进化过程**，并可通过多种方式进行研究。例如，通过比较直系同源基因比对中的[[非同义突变(Non-synonymous mutation)]] 与[[同义突变(Synonymous mutation)]] 速率，可以检测[[正选择(Positive selection)]] 或多样化选择。

在若干密码子位点上，**dN/dS 比值**可能显著高于 1，此类位点通常被视为受到**正选择作用**。例如，当特定氨基酸变化能够提高宿主对病原体的适应度时，这些变化可能受到偏好。反之，病原体基因本身也可能受到**选择压力的影响**。正选择的检测有助于研究者理解基因的演化历程，从而制定应对持续与宿主进行“军备竞赛”的病原体的策略。

由于**重组**会深刻影响进化过程，并可能干扰系统发育推断及正选择的准确检测，因此，在比对中筛查断点以界定潜在的**重组片段**应成为任何比较进化研究的标准步骤。对**显著正选择位点进行全面的进化分析通常包含一系列复杂步骤**，包括：
1. 开放**阅读框对齐**
2. 缺失插入**校正**
3. **系统发育树构建**
4. 最佳**核苷酸替换模型**选择
5. 拓扑不一致检测及断点筛查以描述潜在**重组事件**
6. 在不同模型下识别**正选择位点**（x > 1）
7. 评估这些位点对整体**选择压力**的影响。
## 科学问题
- 由此可见，此类分析依赖**大量工具**及参数设置，且使用广泛的工具往往**难以解释和处理结果**。
- 尤其是潜在重组事件的精确检测与处理，更是**艰巨而关键的任务**。
- 目前，能够实现综合正选择检测的**工具数量有限**。
- 这些工具要么无法自动整合上述所有步骤，要么未考虑潜在重组事件，要么仅关注原核基因组中的正选择检测。

## 研究思路
本研究提出 **PoSeiDon**，这一流程能够自动化执行上述全部任务，从而支持研究者开展全面的进化分析。

# 介绍
PoSeiDon 由一系列脚本与工具组成，用于检测蛋白编码序列中的重组事件和正选择信号。

![图片.png|700](https://picturerealm.oss-cn-chengdu.aliyuncs.com/obsidian/%E5%9B%BE%E7%89%87.png)

所有第三方工具均封装于 Docker 容器中，各步骤通过 **Nextflow** 连接，实现完全并行化与简易的执行方式。在正确配置 Nextflow 与 Docker 后，PoSeiDon 可通过一条命令安装并运行。

此外，不同的执行配置文件使流程能够在**云平台或集群系统中稳定运行**。从用户提供的同源编码序列出发，流程利用 TranslatorX（v1.1）**在氨基酸信息的指导下构建多序列比对**，并通过 Muscle进行[[多序列比对(Multiple sequence alignment, MSA)]]。

所得的保持阅读框的核苷酸比对随后会进行**Indel清理**。利用 MODELTEST，即 HyPhy 工具集（v2.5.14）的一部分，选择**最佳替换模型**。在选定的替换模型下，使用 GARD 检测比对中的**潜在重组事件及其对应断点**。随后，通过 Kishino–Hasegawa（KH）检验评估**所有断点是否存在显著的拓扑不一致**。

对完整比对及各片段的系统发育重建采用 RAxML 完成，并通过 Newick Utilities 工具集进行可视化。

**正选择分析分别在完整比对及每个片段上独立进行**。流程利用 PAML 套件中实现的 CODEML 进行多种位点模型的**最大似然检验**，包括 M1a 与 M2a、M7 与 M8 的比较。

此外，PoSeiDon 还实现了 **M8a 与 M8 的额外模型检验**。这些位点模型的比较**旨在区分不允许密码子以 x > 1 速率进化（中性模型）与允许密码子出现正选择类（选择模型）之间的差异**。随后，采用 Bayes 经验贝叶斯方法计算**各密码子属于 x > 1 类别的后验概率**。**后验概率>0.95 的位点被视为显著正选择位点**。流程对不同频率模型下检测到的所有正选择位点进行图形化总结。这一设计允许用户观察到在 PP 阈值下可能被忽略的位点。例如，当物种取样不足时，位于蛋白调控结构域的位点可能因 PP 偏低而未达到显著性。 PoSeiDon 的最终输出基于经过大幅修改的 TranslatorX HTML 输出格式，使结果呈现更加直观、全面。

# 结论
本研究提出 PoSeiDon，这是一套易于使用的 Nextflow 流程，用于精确检测**蛋白编码序列中的位点特异性正选择与重组事件**。该流程以**同源编码序列的多 FASTA 文件为输入，并自动生成基于密码子的比对**。

鉴于重组对序列进化历史具有深远影响，流程首先通过检测比对中的拓扑不一致来界定潜在重组断点。PoSeiDon 对完整比对及所有可能的片段分别执行独立的进化分析。 流程自动为所有比对构建最大似然系统发育树，估计各位点的 x 值，并评估其在正选择中的作用。所有识别出的正选择位点及其显著性结果均被映射回输入序列的密码子与氨基酸比对，使研究者能够直观定位具有较高 x 值的“进化热点”区域。此外，流程还提供可直接用于发表的 PDF 与 LaTeX 表格，包含所有断点及显著正选择位点。 最终，所有结果均通过用户友好且清晰的方式呈现，使研究者能够系统地开展正选择研究。
