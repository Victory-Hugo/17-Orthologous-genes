
注意，该软件只能处理100条序列。

您只需安装 Nextflow（版本 20.+）和 Docker 即可运行此管道。所有依赖项将自动拉取。

```bash
# 安装 Nextflow（如果尚未安装）

curl -s https://get.nextflow.io | bash
mv nextflow ~/bin/nextflow
```


```bash
# 克隆 PoSeiDon 存储库并运行管道
git clone https://github.com/hoelzer/poseidon.git
cd poseidon
nextflow run poseidon.nf --help
```
或者，您也可以直接从 Nextflow Hub 运行 PoSeiDon：

```bash
nextflow pull hoelzer/poseidon
```

重要：PoSeiDon 需要具有正确开放阅读框的核苷酸序列作为输入。此外，结果在很大程度上取决于您选择的序列；因此，您可能需要使用不同采样的输入序列多次运行该管道。另外，该管道不适用于过多的序列，因为其核心部分使用的是 PAML 套件中的 CODEML，该工具不适用于超过 100 个序列。请参见下方对输入参数和设置的详细描述。

Nextflow 可以在不同的环境中轻松执行，例如本地机器、高性能集群或云环境。不同的 -profile 用于指示 Nextflow 应该使用哪个系统。对于本地执行，应使用 -profile local,docker（并且这是默认设置）。您还可以使用 Singularity 在高性能计算 (HPC) 上运行 PoSeiDon，可以通过 -profile lsf,singularity、-profile slurm,singularity 或 -profile sge,singularity。在这种情况下，请考虑调整 --cachedir 指向集群中 Singularity 图像的存储位置。参数 --workdir 也可能有助于调整临时工作目录的存储位置（例如，根据您的 HPC 配置，可以使用 /scratch 而不是 /tmp）。

现在，假设您使用 Nextflow 拉取了 PoSeiDon 代码，并在本地机器上使用默认配置文件 -profile local,docker 执行了该管道。

```bash
# show help 
nextflow run hoelzer/poseidon --help

# run small example on a local machine with 
# (first time this will need some more time because the Docker containers are downloaded)
nextflow run hoelzer/poseidon -r v1.0.1 --fasta ~/.nextflow/assets/hoelzer/poseidon/test_data/bats_mx1_small.fasta \
--cores 4

# resume a broken run
nextflow run hoelzer/poseidon -r v1.0.1 --fasta ~/.nextflow/assets/hoelzer/poseidon/test_data/bats_mx1_small.fasta \
--cores 4 -resume

# instead of using all available cores only use a maximum amount on the local machine
nextflow run hoelzer/poseidon -r v1.0.1 --fasta ~/.nextflow/assets/hoelzer/poseidon/test_data/bats_mx1_small.fasta \
--max_cores 8
--cores 4
```
