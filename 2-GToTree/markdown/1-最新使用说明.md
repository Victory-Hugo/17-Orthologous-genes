# GToTree v1.8.16 使用指南

GitHub 地址：[github.com/AstrobioMike/GToTree](https://github.com/AstrobioMike/GToTree)

## 帮助信息

GToTree 是一个能够从多种来源的基因组输入中构建系统发育树的工具。

详细使用说明请参考 Wiki：  
<https://github.com/AstrobioMike/GToTree/wiki>

---

## 必需输入

### 1. 输入基因组格式

可选择以下一种或多种格式输入基因组：

- `-a <文件>`：单列文件，包含 NCBI 装配访问号
- `-g <文件>`：单列文件，包含 GenBank 文件路径
- `-f <文件>`：单列文件，包含 fasta 文件路径
- `-A <文件>`：单列文件，包含氨基酸文件路径，每个文件仅包含一个基因组的编码序列

### 2. SCGs HMM 文件

使用 `-H <文件>` 指定 HMM 文件（未压缩），也可以在设置好 `GToTree_HMM_dir` 环境变量（如通过 conda 安装后）直接提供基因集名字，运行 `gtt-hmms` 可以查看所有可用基因集。

## 可选输入

### 输出目录

- `-o <字符串>`：设置输出目录，默认 `GToTree_output`。

### 基因组标签映射

- `-m <文件>`：自定义基因组标签映射文件（tab 分隔，2 或 3 列）
  - 第 1 列：输入基因组文件名或 NCBI accession
  - 第 2 列：新标签（可空）
  - 第 3 列：要追加的标签信息（可空，用于标记特征）

---

### 添加分类信息

- `-t`：添加 NCBI 分类信息（默认：false）  
  基于 NCBI taxid 添加分类信息，适用于通过 `-a`（访问号）输入的基因组，也会查找 GenBank 输入中的 taxid。可配合 `-L` 指定分类层级。

- `-D`：添加 GTDB 分类信息（默认：false）  
  从 GTDB（Genome Taxonomy Database）加载分类信息，仅适用于通过 `-a` 输入的基因组。可与 `-t` 配合使用，未匹配 GTDB 的会添加 NCBI 分类并附加 `_NCBI`。

- `-L <字符串>`：指定分类等级（默认：`Domain,Phylum,Class,Species,Strain`）  
  逗号分隔，如全部等级：  
  `-L Domain,Phylum,Class,Order,Family,Genus,Species,Strain`。  
  注意 GTDB 不提供菌株（Strain）等级。

---

### 过滤设置

- `-c <浮点数>`：序列长度过滤范围（默认：`0.2`）  
  按中位数 ±20% 过滤序列长度异常的区域。

- `-G <浮点数>`：基因组 SCG 命中比例过滤（默认：`0.5`）  
  若 SCG 目标集合有 100 个基因，而某基因组仅有 49 个命中，将被过滤。

- `-B`：最佳命中模式（默认：false）  
  默认 SCG 存在多个命中时丢弃该基因。启用该选项后将使用最佳命中序列。

---

### KO 搜索

- `-K <文件>`：提供包含 KEGG Orthology ID 的单列文件  
  会生成命中计数表、命中序列 fasta 文件，以及适用于 iToL 可视化的文件。

### Pfam 搜索

- `-p <文件>`：提供包含 Pfam ID 的单列文件  
  功能同 `-K`。

---

### 通用运行设置

- `-z`：启用核苷酸模式（默认：false）  
  用核苷酸序列进行比对或构树，仅支持 `-a` 和 `-f` 两种输入方式。

- `-N`：不构建树（默认：false）  
  只生成比对，不生成系统发育树。

- `-k`：保留每个目标基因的独立比对（默认：false）。

- `-T <字符串>`：指定构树程序（默认：优先 FastTreeMP，然后 FastTree）  
  可选 `"FastTree"`, `"FastTreeMP"`, `"VeryFastTree"`, `"IQ-TREE"`。

- `-n <整数>`：HMM 搜索使用的 CPU 数（默认：2）

- `-M <整数>`：Muscle 比对线程数（默认：5）

- `-j <整数>`：并行任务数（默认：1）  
  注意并发下载过多（~50）时可能引发 NCBI 限流。

- `-X`：覆盖 super5 比对模式（默认：false）

- `-P`：使用 http 替代 ftp 下载（默认：false）

- `-F`：强制覆盖已存在输出目录（默认：false）

- `-d`：调试模式，保留临时文件（默认：false）

---

## 示例命令

```bash
GToTree -a ncbi_accessions.txt -f fasta_files.txt -H Bacteria -D -j 4
```
