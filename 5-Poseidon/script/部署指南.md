# PoSeiDon 离线部署指南

## 概述

本指南帮助您在没有网络连接的服务器上部署 PoSeiDon 流水线所需的 Docker 镜像。PoSeiDon 是一个用于正向选择检测和重组分析的生物信息学流水线。

## 所需镜像列表

PoSeiDon 流水线需要以下 8 个 Docker 镜像：

| 功能模块 | Docker 镜像 | 用途 |
|---------|-------------|------|
| 序列翻译对齐 | nanozoo/translatorx:1.1--1f1af23 | TranslatorX 序列翻译和对齐 |
| Ruby 工具 | nanozoo/bioruby:2.0.1--1f8a188 | 生物信息学 Ruby 脚本 |
| 文档生成 | nanozoo/texlive-core:3.14159265--bb5506c | LaTeX 报告生成 |
| 进化树构建 | nanozoo/raxml:8.2.12--27d10cf | RAxML 系统发育分析 |
| 树文件处理 | nanozoo/newick_utils:1.6--014d613 | Newick 格式树文件操作 |
| 模型选择 | nanozoo/hyphy:2.5.14--ed56f29 | HyPhy 模型选择 |
| 重组检测 | nanozoo/hyphy:2.2.7--9dc0fe5 | GARD 重组检测 |
| 正向选择 | nanozoo/paml:4.9--cff12e2 | PAML/CodeML 正向选择分析 |

## 部署步骤

### 第一步：在有网络的环境中打包镜像

1. **准备环境**
   - 确保已安装 Docker
   - 确保有足够的磁盘空间（约 5-8GB）

2. **执行打包脚本**
   ```bash
   cd /mnt/l/Docker-package
   ./pull_and_save_images.sh
   ```

3. **验证打包结果**
   ```bash
   ls -lh docker_images/
   # 应该看到 8 个 .tar 文件和 1 个映射文件
   ```

4. **打包传输文件**
   ```bash
   tar -czf poseidon_docker_images.tar.gz docker_images/ *.sh docker_images_list.txt
   ```

### 第二步：传输到离线服务器

将 `poseidon_docker_images.tar.gz` 文件传输到目标服务器：

```bash
# 使用 scp 传输（如果有网络连接）
scp poseidon_docker_images.tar.gz user@server:/path/to/destination/

# 或使用 rsync
rsync -avz poseidon_docker_images.tar.gz user@server:/path/to/destination/

# 或使用其他物理介质传输方法
```

### 第三步：在离线服务器上部署

1. **解压文件**
   ```bash
   tar -xzf poseidon_docker_images.tar.gz
   cd Docker-package/
   ```

2. **加载 Docker 镜像**
   ```bash
   ./load_images.sh
   ```

3. **验证镜像加载**
   ```bash
   docker images | grep nanozoo
   ```
   
   应该看到所有 8 个镜像都已成功加载。

### 第四步：配置 Nextflow

1. **确保 Nextflow 已安装**
   ```bash
   # 检查 Nextflow 版本（需要 >= 23.01.0）
   nextflow -version
   ```

2. **配置 Docker 支持**
   - 确保当前用户可以运行 Docker 命令
   - 如果需要，将用户加入 docker 组：
   ```bash
   sudo usermod -aG docker $USER
   # 需要重新登录生效
   ```

### 第五步：运行 PoSeiDon 流水线

使用以下命令运行 PoSeiDon：

```bash
nextflow run /path/to/poseidon.nf \
    --fasta /path/to/your/input.fasta \
    --output /path/to/output/directory \
    --cores 4 \
    --memory "16" \
    --max_cores "16" \
    -profile docker
```

关键参数说明：
- `--fasta`: 输入的 FASTA 序列文件
- `--output`: 输出目录
- `--cores`: 每个进程使用的核心数
- `--memory`: 内存限制（GB）
- `--max_cores`: 最大核心数
- `-profile docker`: 使用 Docker 容器运行

## 故障排除

### 常见问题

1. **Docker 权限问题**
   ```bash
   # 确保用户在 docker 组中
   groups $USER
   
   # 如果不在，执行：
   sudo usermod -aG docker $USER
   # 然后重新登录
   ```

2. **内存不足**
   - 减少 `--cores` 和 `--max_cores` 参数
   - 增加 `--memory` 参数

3. **磁盘空间不足**
   - 清理不需要的 Docker 镜像和容器
   - 确保工作目录有足够空间

4. **Nextflow 版本问题**
   ```bash
   # 更新 Nextflow
   nextflow self-update
   ```

### 验证命令

```bash
# 检查 Docker 镜像
docker images | grep nanozoo

# 检查 Nextflow
nextflow -version

# 测试简单命令
docker run --rm nanozoo/bioruby:2.0.1--1f8a188 ruby --version
```

## 清理和维护

### 清理临时文件
```bash
# 清理 Nextflow 工作目录
rm -rf work/

# 清理 Docker 临时容器
docker container prune -f

# 清理未使用的镜像
docker image prune -f
```

### 更新镜像
如果需要更新镜像，重复第一步和第二步的过程。

## 支持信息

- **PoSeiDon 版本**: 1.1.1
- **Nextflow 最低版本**: 23.01.0
- **Docker 最低版本**: 19.03+
- **所需磁盘空间**: 约 8GB（镜像 + 工作空间）
- **所需内存**: 最低 8GB，推荐 16GB+
