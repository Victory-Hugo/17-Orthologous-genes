## Rv1819c-like 蛋白过滤标准

### 1. 必须条件（不满足即剔除）

- Pfam 命中 **ABC_tran**（或 ABC_N / ABC_ATPase），`i-Evalue ≤ 1e-10`
- Pfam 命中 **ABC_membrane_2**（优先）或其它 ABC transporter membrane 域，`i-Evalue ≤ 1e-10`
- TMHMM 预测跨膜螺旋数 **PredHel ≥ 4**
- 结构顺序满足：**TMD 在前，NBD 在后**
    - 定义：`NBD_start − last_TM_end ≥ 0`
    - 推荐窗口：`0 ≤ gap ≤ 250 aa`

---

### 2. 排除条件（命中即不进入主分析集合）

- Pfam 命中 **ABC_sub_bind** 或 **BCA_ABC_TP_C**
- TMHMM `PredHel ≤ 2` 且 SignalP 预测为信号肽阳性

---

### 3. SignalP 使用原则

- SignalP-TM **不作为剔除条件**
- 仅与 TM 数过少（≤2）联合使用作为排除依据

---

### 4. 分类输出（用于后续分析）

- **A 类（高置信）**：满足全部必须条件
- **B 类（低置信）**：满足 NBD + TMD，但 gap 或 TM 数异常
- **C 类（剔除）**：不满足必须条件或命中排除条件
