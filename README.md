# 仓库介绍
本代码仓库主要实现2个目的：
1. 构建基因树
2. 构建物种树
**十分推荐直接使用GTDB数据库中的数据进行分析，GTDB数据库已经预先处理好了基因预测和注释工作，可以节省大量时间**。

# 结构
流程如下：
1. 数据准备:从公共数据库下载基因组数据。公共数据库包括：NCBI、GTDB等。
2. 基因预测:如果下载的数据已经有了基因注释文件，则跳过此步骤。否则，使用工具（如Prokka、Prodigal等）进行基因预测。
3. 多序列对齐:使用工具（如MAFFT、MUSCLE等）对**选定的基因**进行多序列对齐。选择的基因可以是单拷贝基因、核心基因等。
4. 物种树构建:使用对齐后的序列构建物种树。常用的工具包括RAxML、IQ-TREE等。
5. 基因树构建:使用对齐后的基因序列构建基因树。常用的工具包括RAxML、IQ-TREE等。
6. 结果可视化:使用工具（如iTOL、FigTree等）对构建的树进行可视化。
