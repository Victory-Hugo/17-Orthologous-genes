# 仓库介绍
本仓库的代码有多种功能，且还在持续更新……

# 结构
1. 0-GTDB数据库：用于运行GTDB-TK的基础功能。
2. 1-数据获取：用于下载NCBI的基因数据。
3. 1-HMM：针对下载的数据进行HMM建库+搜索+从物种中提取序列+比对+同义非同义突变。
4. 2-GToTree：用于构建系统发育树。一站式工作。输入为多个物种的FASTA文件，一键构建系统发育树。
5. 3-目标序列理化性质挖掘：对faa序列进行理化性质分析。
6. 9-BUSCO(弃用)：早期用于构建系统发育树，现已弃用，推荐使用GToTree。
7. 9-PoSeiDon：用于检测基因重组事件并计算正负选择压力。（缺点：仅支持不到100个序列）。
