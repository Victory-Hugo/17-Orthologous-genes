# 各脚本的功能

以下内容面向首次接触 HMM→Ka/Ks 管线的同学，按照 LolD 基因示例说明每个脚本在流水线中的作用、输入与输出。只要替换 query 名称（如 lolF）即可扩展到其他基因。

## 4-提取匹配序列.py
- **用途**：从合并后的 `tbl_merge.tsv` 中读取指定菌株的 HMM 命中信息，并把命中的蛋白序列从该菌株的 `.faa` 中剪出来，可按 E-value、覆盖度、长度进行过滤，并支持 “只保留最高分” 模式。
- **使用方式**：直接运行 Python 程序，例如  
  `python3 4-提取匹配序列.py <sample.faa> output/tbl_merge.tsv output/ --max-evalue 1e-20 --min-length 180 --mode only_one --model-length 225`
- **输出**：`output/<query>/<sample>.hits.faa`，每条序列 Header 包含 target id、score、E-value、长度、覆盖度。

## 4-并行提取匹配序列.sh
- **用途**：批量调用上面的 Python 脚本，对 `conf/1-prodigal_faa_list.txt` 中列出的所有菌株并行提取最佳命中。
- **输入**：
  - `conf/1-prodigal_faa_list.txt`：菌株蛋白 FASTA 列表。
  - `output/tbl_merge.tsv`：HMM 搜索结果。
  - 脚本开头可配置的过滤阈值（E-value、覆盖度、长度、only_one/all）。
- **输出**：更新 `output/<query>/` 或 `<query>.trim/` 中的 `.hits.faa`；`parallel_extract.log` 记录日志。
- **LolD 示例**：直接运行 `./4-并行提取匹配序列.sh`，脚本会读取 `conf/1-prodigal_faa_list.txt` 并自动把 LolD 的命中写入 `output/lolD.trim/`。

## 4-1-整理HMM命中列表（.sh -> .py）
- **用途**：把 `*.hits.faa` 目录里所有 query 的命中信息汇总成一张 TSV，便于后续批量提取 CDS 与蛋白。对任何 gene 适用。
- **使用方式**：修改 `4-1-整理HMM命中列表.sh` 开头的 `HITS_DIR/OUTPUT_TSV/QUERIES`（`QUERIES=()` 表示全部），运行 `./4-1-整理HMM命中列表.sh`。
- **输出**：`hits_manifest.tsv`，包含 sample、target id、score、E-value、覆盖度、氨基酸序列等信息。

## 4-2-提取命中CDS蛋白序列（.sh -> .py）
- **用途**：根据 `hits_manifest.tsv` 在各菌株 `.ffn` 中抓取对应 CDS，同时收集蛋白序列。
- **使用方式**：设置 `4-2-提取命中CDS蛋白序列.sh` 的 `MANIFEST/SAMPLE_DIR/OUTPUT_DIR/QUERIES` 后执行 `./4-2-提取命中CDS蛋白序列.sh`。
- **输出**：`output/LolD_pipeline/sequences/` 下的 `protein/<query>.faa`、`cds/<query>.ffn`、`summary.tsv`。

## 5-1-蛋白多序列比对.sh
- **用途**：使用 MAFFT 对 `sequences/protein/*.faa` 做多序列比对。
- **输入**：脚本里配置的 `INPUT_DIR`（如 `.../sequences/protein`）。
- **输出**：`alignments/protein/<query>.aln.faa`。
- **示例**：直接运行脚本即可完成 `lolD.trim.faa` 的 MSA。

## 5-2-蛋白CDS转密码子比对（.py -> PAL2NAL）
- **用途**：调用专业工具 **PAL2NAL**，利用蛋白 MSA + CDS FASTA 生成密码子对齐，并可额外导出 all-vs-all AXT。
- **使用方式**：该 Python 程序通常由 `5-下游KaKs流水线.sh` 调用；若需单独运行，可手动执行 `python3 5-2-蛋白CDS转密码子比对.py --alignment-dir ... --cds-dir ...` 并传入 `--pal2nal-bin/--codon-table/--axt-dir/--queries` 等参数。请确保系统已安装 PAL2NAL（Perl 脚本）。
- **输出**：`alignments/codon/<query>.codon.fna`（PAL2NAL 生成）以及可选的 `alignments/axt_all/<query>.all_pairs.axt`。

## 6-1-构建KaKs参考AXT.py
- **用途**：从密码子对齐中挑选参考序列，与其它序列组成 KaKs_Calculator 所需 AXT。
- **使用方式**：默认由 `5-下游KaKs流水线.sh` 自动调用，可通过 `--reference/--queries` 等参数控制；亦可单独运行 Python 脚本。
- **输出**：`axt/<query>.ref_<reference>.axt` 与 `axt_summary.tsv`。

## 6-2-运行 KaKs_Calculator（集成在 5-下游KaKs流水线.sh）
- **用途**：批量调用 KaKs_Calculator3，对 `axt/*.axt` 运行 Ka/Ks 计算。
- **配置**：`5-下游KaKs流水线.sh` 顶部提供 `KAKS_DIR` 与 `KAKS_BIN` 参数，指向 KaKs_Calculator3 的可执行文件；同时可设置输出目录。
- **输出**：`output/LolD_pipeline/kaks/<query>.ref_xxx.kaks.tsv`，内含每对序列的 Ka、Ks、Ka/Ks。

## 7-1-统计KaKs结果.py / 7-2-绘制KaKs分布.py
- **用途**：整合 `kaks/*.kaks.tsv` 并输出统计摘要；随后根据 `KaKs_summary.tsv` 绘制 Ka/Ks 分布图。
- **使用方式**：两者均由 `5-下游KaKs流水线.sh` 按顺序自动调用，也可以分别运行 Python 程序。
- **输出**：`KaKs_summary.tsv`、`KaKs_stats.tsv`、`KaKs_per_method.tsv` 以及 `kaks_hist.png`、`ka_vs_ks.png`、`kaks_category.png`。

- **输出**：`alignments/codon/<query>.codon.fna`（PAL2NAL 生成）以及可选的 `alignments/axt_all/<query>.all_pairs.axt`。

## 5-下游KaKs流水线.sh
- **用途**：将 PAL2NAL → 参考 AXT → KaKs_Calculator → 统计 → 绘图 五个步骤一键串联。脚本带有详细日志（INFO/WARN/ERROR）与依赖说明，便于排查。
- **使用方式**：编辑脚本顶部的配置（蛋白/ CDS/输出目录、参考序列、PAL2NAL 与 KaKs_Calculator 路径、方法过滤等），运行 `./5-下游KaKs流水线.sh` 即可生成密码子对齐、Ka/Ks 结果和图表。
- **输出**：`alignments/codon/`、`alignments/axt_all/`、`axt/`、`kaks/`、`kaks_stats/`、`kaks_plots/` 等目录下的全部结果文件。

## LolD→Ka/Ks 分析流程（ASCII 示意）
```
[配置文件]
│   conf/1-prodigal_faa_list.txt
│   conf/2-hmm库_list.txt
│
└──(HMM 搜索) 已完成 -> output/tbl_merge.tsv
      │
      ▼
[4-并行提取匹配序列.sh]
      │ 读取 tbl_merge + 所有 sample.faa
      ▼
output/lolD/*.hits.faa
      │
      ├─[4-1-整理HMM命中列表.sh]  -> hits_manifest.tsv
      │
      └─[4-2-提取命中CDS蛋白序列.sh]
             ├─protein/lolD.faa
             └─cds/lolD.ffn
                      │
                      ▼
           [5-1-蛋白多序列比对.sh]
           [5-下游KaKs流水线.sh]
                 │
                 ├─PAL2NAL -> alignments/codon + AXT(all_pairs)
                 ├─参考 AXT -> axt/lolD.ref_<ref>.axt
                 ├─KaKs_Calculator -> kaks/*.kaks.tsv
                 ├─统计 (KaKs_summary / stats)
                 └─绘图 (kaks_hist/ka_vs_ks/kaks_category)
```

照此顺序即可从 LolD HMM 命中一路推进到 Ka/Ks 统计。其他基因只需把 `--queries` 换成相应的 query 名称即可复用整条流水线。
